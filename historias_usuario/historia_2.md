# Historia de usuario 2: Inicio de sesión

## Historia de usuario

Como **usuario registrado**, quiero **iniciar sesión con mi correo y contraseña**, para **acceder de manera segura a las funcionalidades de la aplicación**.

## Criterios de aceptación

- El sistema debe mostrar un formulario con correo electrónico y contraseña.
- El sistema debe validar que ambos campos sean obligatorios.
- El sistema debe permitir el acceso únicamente si las credenciales son correctas.
- Si las credenciales son incorrectas, el sistema debe mostrar un mensaje de error.
- Al iniciar sesión correctamente, el usuario debe ser dirigido a la pantalla principal o menú de productos.
- La sesión del usuario debe mantenerse activa mientras utiliza la aplicación.
