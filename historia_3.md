# Historia de usuario 3: Explorar menú

## Historia de usuario

Como **cliente**, quiero **visualizar el menú de la cafetería con productos, precios y descripciones**, para **elegir lo que deseo comprar**.

## Criterios de aceptación

- El sistema debe mostrar una lista de productos disponibles.
- Cada producto debe mostrar nombre, descripción, precio y categoría.
- El usuario debe poder distinguir entre cafés, bebidas, postres u otras categorías.
- Si no existen productos disponibles, el sistema debe mostrar un mensaje informativo.
- El usuario debe poder seleccionar un producto para agregarlo al carrito.
- La información del menú debe presentarse de forma clara y ordenada.
