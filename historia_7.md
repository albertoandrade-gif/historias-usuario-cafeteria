# Historia de usuario 7: Historial de pedidos

## Historia de usuario

Como **cliente**, quiero **consultar mi historial de pedidos anteriores**, para **revisar las compras que he realizado en la cafetería**.

## Criterios de aceptación

- El sistema debe mostrar una lista de pedidos realizados por el usuario.
- Cada pedido debe mostrar número de orden, fecha, total y estado.
- Si el usuario no tiene pedidos anteriores, el sistema debe mostrar un mensaje informativo.
- El usuario debe poder seleccionar un pedido para revisar su detalle.
- El historial debe mostrar únicamente los pedidos del usuario autenticado.
- Los pedidos deben ordenarse preferentemente desde el más reciente al más antiguo.
