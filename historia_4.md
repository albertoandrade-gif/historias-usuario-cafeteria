# Historia de usuario 4: Agregar productos al carrito

## Historia de usuario

Como **cliente**, quiero **agregar productos al carrito y seleccionar la cantidad deseada**, para **preparar mi pedido antes de confirmarlo**.

## Criterios de aceptación

- El usuario debe poder agregar un producto desde el menú al carrito.
- El sistema debe permitir seleccionar o modificar la cantidad del producto.
- El sistema debe calcular el subtotal de cada producto según su precio y cantidad.
- El sistema debe mostrar el total acumulado del carrito.
- Si el producto ya existe en el carrito, el sistema debe actualizar la cantidad en lugar de duplicarlo.
- El usuario debe recibir una confirmación visual cuando el producto sea agregado correctamente.
