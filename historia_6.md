# Historia de usuario 6: Realizar pedido

## Historia de usuario

Como **cliente**, quiero **confirmar mi pedido y seleccionar un método de pago simulado**, para **generar una orden de compra en la cafetería**.

## Criterios de aceptación

- El sistema debe mostrar un resumen del pedido antes de confirmarlo.
- El resumen debe incluir productos, cantidades, subtotales y total final.
- El usuario debe seleccionar un método de pago simulado.
- El sistema debe solicitar confirmación antes de generar la orden.
- Al confirmar el pedido, el sistema debe generar un número de orden.
- El sistema debe mostrar un mensaje de pedido realizado exitosamente.
- El pedido confirmado debe guardarse en el historial del usuario.
