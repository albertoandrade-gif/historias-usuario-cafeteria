# Historia de usuario 5: Modificar carrito

## Historia de usuario

Como **cliente**, quiero **modificar los productos de mi carrito antes de confirmar el pedido**, para **corregir cantidades o eliminar productos que ya no deseo comprar**.

## Criterios de aceptación

- El sistema debe mostrar todos los productos agregados al carrito.
- El usuario debe poder aumentar o disminuir la cantidad de cada producto.
- El usuario debe poder eliminar productos del carrito.
- El total del carrito debe actualizarse automáticamente cuando se modifiquen cantidades.
- Si el carrito queda vacío, el sistema debe mostrar un mensaje indicando que no hay productos seleccionados.
- El sistema no debe permitir confirmar un pedido con el carrito vacío.
