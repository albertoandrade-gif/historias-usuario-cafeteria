# Historia de usuario 8: Consultar detalle de pedido

## Historia de usuario

Como **cliente**, quiero **ver el detalle completo de una orden específica**, para **confirmar qué productos compré, sus cantidades y el total pagado**.

## Criterios de aceptación

- El sistema debe permitir abrir el detalle desde el historial de pedidos.
- El detalle debe mostrar número de orden, fecha, productos, cantidades, precios unitarios, subtotales y total.
- El sistema debe mostrar el estado del pedido.
- El usuario solo debe poder consultar pedidos asociados a su propia cuenta.
- Si la orden no existe, el sistema debe mostrar un mensaje de error.
- El usuario debe poder regresar al historial de pedidos desde la pantalla de detalle.
