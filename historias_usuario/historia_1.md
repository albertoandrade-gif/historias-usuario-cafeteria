# Historia de usuario 1: Registro de usuario

## Historia de usuario

Como **cliente nuevo**, quiero **crear una cuenta con mi correo electrónico y contraseña**, para **poder acceder a la aplicación y realizar pedidos en la cafetería**.

## Criterios de aceptación

- El sistema debe mostrar un formulario de registro con nombre, correo electrónico y contraseña.
- El sistema debe validar que el correo electrónico tenga un formato válido.
- El sistema debe impedir el registro si el correo ya se encuentra registrado.
- El sistema debe solicitar una contraseña obligatoria.
- Cuando el registro sea exitoso, el sistema debe mostrar un mensaje de confirmación.
- El usuario registrado debe poder iniciar sesión posteriormente con sus credenciales.
